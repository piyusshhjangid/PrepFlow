# Prize category decision and evidence matrix

Candidate category: **Best Use of Gemma** only. The app integrates Gemma locally through Ollama, but this audit could not run the Ollama service or a real Gemma model. The category permits running Gemma locally, fine-tuning it, or serving it through Google Cloud or another provider; whether this project meets the category requirement is unverified. This document does not claim that the category was entered.

| Candidate                        | Genuine fit                                                                                                                       | Verdict     |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | ----------- |
| **Best Use of Gemma**            | The intended model job is topic extraction from free text; integration exists, but no real-model run is verified | Candidate only |
| Best Use of Render               | Weak: local-first app; a hosted copy cannot reach a visitor's Ollama, and hosted Gemma would contradict the privacy story         | Not entered |
| Best Use of Sentry Agent Tracing | Weak: no agent; one bounded call per chunk                                                                                        | Not entered |
| Best Use of Tinker               | Would need a fine-tune with a measured improvement                                                                                | Not entered |
