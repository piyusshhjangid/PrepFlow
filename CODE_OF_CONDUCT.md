# Code of Conduct

Everyone participating in PrepFlow spaces and contributions is expected to be respectful and constructive. Harassment, discrimination, personal attacks, intimidation, and sharing private information without consent are not acceptable.

Maintain a welcoming environment, assume good intent while addressing impact, and focus criticism on work and ideas. Follow the same standards in issues, pull requests, reviews and project discussions.

Project maintainers may edit or remove contributions that violate these standards and may restrict participation when needed. To report a concern, contact the repository maintainers through the private channel listed on the repository hosting service. This project snapshot does not identify an individual contact.
