# Genuine screenshot checklist

Capture the running application with real interface state. Use fictional or consented material, hide workspace UUIDs, remove personal names and avoid editing images to imply behavior that did not occur.

- [ ] Landing page
- [ ] Setup with exam date, study days and daily hours
- [ ] Material paste or PDF upload
- [ ] Analysis page with truthful server-reported stage
- [ ] Topic review with evidence, priority, effort and weak status
- [ ] Generated plan with daily capacity and fit/deferred explanation
- [ ] Today with tasks, duration and revision due state
- [ ] Progress with completed and remaining work
- [ ] Provider configuration only if it contains no API key or secret

Also check one narrow mobile viewport and one desktop viewport. Record viewport sizes and date in the submission notes. No screenshots are included until actually captured.
