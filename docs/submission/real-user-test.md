# Friend test protocol

## Status: PENDING

## Preparation

- Ask the friend for permission to observe and to take notes. Ask separately before using any quote, name, screenshot or study material in a public post.
- Use their own non-sensitive material only if they choose to provide it. Otherwise use fictional material and do not call the session a real-content test.
- Confirm a deployed or local environment is ready, the actual AI provider is identified, and the test can be reset without losing material they care about.
- Ask the friend to think aloud while they set up an exam, add material, review topics, generate a plan, open Today and complete a task.

## Questions

1. What did you find useful?
2. What was confusing?
3. Did the plan reflect how you study?
4. Would you use it before an exam?
5. What would you change?
